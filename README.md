# RouteWalkAR — 法務ページ

Android XR 向け徒歩ナビゲーションアプリ **RouteWalkAR** のプライバシーポリシーと
利用規約を公開するためのリポジトリ。GitHub Pages で配信する。

アプリ本体のソースは別の非公開リポジトリにある。ここにはこの3ページ以外を置かない。

| ファイル | 公開URL |
|---|---|
| `index.html` | `https://noritsune.github.io/routewalkar-legal/` |
| `privacy-policy.html` | `https://noritsune.github.io/routewalkar-legal/privacy-policy.html` |
| `terms-of-use.html` | `https://noritsune.github.io/routewalkar-legal/terms-of-use.html` |

プライバシーポリシーのURLは Google Play Console の
「アプリのコンテンツ → プライバシーポリシー」に登録する。

## 公開の設定

Settings → Pages → Source を `Deploy from a branch`、ブランチを `main` / `(root)` にする。

## 更新するとき

アプリの機能を変えて、取り扱う情報や権限が変わったら、このページも直して制定日を更新する。
文面の元になっている Markdown はアプリ側リポジトリの `docs/store/` にある。
